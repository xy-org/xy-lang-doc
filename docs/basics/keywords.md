# Keywords

| Keyword      | Description       |
|:-------------|:------------------|
| import       | modules           |
| def          | function          |
| don          | function          |
| return, error       | function          |
| mut          | functions, variables |
| true, false         | Bools          |
| for, while, do  | Loops          |
| in            | Loops, Indices          |
| break, continue   | Loops, modules |
| if, else, elif | Branches |
| struct | Structures |
| pseudo | Functions, Structures |

## Reserved Words

The following words are reserved for future use:

```
ref, module, class, out, switch, case, goto
```
